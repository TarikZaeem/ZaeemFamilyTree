# شجرة عائلة (مرتجى الزعيم الشيخ)

شجرة عائلة تفاعلية بالعربية، تعرض أبناء العائلة الذكور على مدى 10 أجيال، من الجد الجامع **عبد المرتجي (الزعيم)** إلى اليوم.

**الموقع:** https://tarikzaeem.github.io/ZaeemFamilyTree/

الموقع للعرض والبحث فقط، ويعمل على الجوال والكمبيوتر بدون تسجيل دخول.

## ما الذي يقدّمه الموقع

- **شجرة قابلة للطي والفتح:** كل الفروع مطويّة في البداية، وتفتح فرعاً فرعاً بالضغط على الاسم.
- **بحث بالنسب:** اكتب الاسم واسم الأب والجد بنفس الحقل، مثل `طارق زياد محمود`. يفهم الأسماء المركبة مثل «عبد الرحمن»، ويتجاهل كلمة «بن».
- **التنقل بين النتائج:** أزرار «السابق» و«التالي» عند وجود أكثر من نتيجة.
- **بطاقة لكل شخص:** نافذة منبثقة فيها الجيل والنسب الكامل وسنة الميلاد والإقامة، ونبذة عن الشخص إن وُجدت.
- **عن العائلة:** أصل العائلة ونبذة تاريخية وإحصاءات (عدد الأفراد والأجيال وأماكن الإقامة).
- **طلب إضافة أو تعديل:** زر يفتح محادثة واتساب جاهزة فيها الاسم الكامل للشخص.
- **عرض مناسب للجوال:** أيقونة بحث وقائمة منسدلة، وتنويه قابل للطي.

| `README.md` | هذا الملف. |

## تحديث الشجرة

التعديلات (إضافة الأبناء والحذف وتعديل البطاقات) تتم في نسخة التحرير الخاصة، وليست في هذا الموقع. بعد التعديل:

1. صدّر **data.json** من نافذة «تصدير واستيراد» ← «تحديث الأسماء فقط».
2. ارفعه إلى هذا المستودع بنفس الاسم `data.json` (**Add file ← Upload files**، ثم **Commit changes**).
3. بعد دقيقة أو دقيقتين يظهر التحديث في الموقع.

إذا تغيّر شكل الموقع أو أُضيفت ميزة جديدة، يُرفع `index.html` الجديد أيضاً بنفس الطريقة.

### التأكد من أن الملفات الصحيحة تعمل

افتح نافذة «عن العائلة» في الموقع، وفي آخرها سطر مثل:

> نسخة الصفحة 43 (2026-10-13) · آخر تحديث للبيانات: 13/10/2026 14:02 · البيانات من data.json

- **نسخة الصفحة:** تتبع ملف `index.html`.
- **آخر تحديث للبيانات:** يتبع ملف `data.json`.
- عبارة **«البيانات من data.json»** تعني أن الموقع قرأ الملف فعلاً.

إذا بدا الموقع قديماً بعد الرفع، افتحه في نافذة خاصة (Private) أو امسح بيانات الموقع من المتصفح.

## صيغة data.json

ملف JSON فيه أشخاص وبيانات العائلة:

```json
{
  "about": { "title": "…", "origin": "…", "text": "…" },
  "people": {
    "معرّف-الشخص": {
      "name": "الاسم",
      "parent": "معرّف-الأب",
      "order": 1,
      "born": 2000,
      "dead": false,
      "died": 0,
      "place": "فلسطين - غزة",
      "bio": "نبذة اختيارية"
    }
  }
}
```

- `parent` فاضي للجد الأول.
- `born` و`died` سنوات من أربعة أرقام، والقيمة `0` تعني «غير مسجّل».
- الموقع يقبل أيضاً ملف JSON العادي (قائمة من الأشخاص يحمل كل واحد منهم `id`).
- إذا كان الملف تالفاً (فقدت معظم الأسماء آباءها)، يتجاهله الموقع ويعرض البيانات المضمّنة.
